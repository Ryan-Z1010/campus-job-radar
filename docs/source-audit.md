为什么不直接全部启用：通用 HTML 爬虫对动态站点可能返回 200，但实际得到的只是空页面框架。这样的“成功”最危险，因为它不会报错，却会漏掉岗位。

采集与审计请求遇到 TLS 意外断连、超时、连接错误，或 HTTP
408、425、429、500、502、503、504 时，会在 0.5 秒后重试一次。证书校验
失败以及 401、403、404 等确定性错误不会重试，仍会作为来源异常进入运行
结果。这样可以吸收短暂网络波动，同时避免掩盖访问限制和站点改版。

每个专用适配器启用前必须验证：

- 连续多次能返回职位；
- 岗位 ID、标题、城市、发布时间、截止日期和详情链接映射正确；
- 空结果与接口故障可区分；
- 请求频率保守；
- 不需要登录、Cookie、验证码或私有凭据。
